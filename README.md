# Growth — 把想法，做成实物。

Growth 助手的独立静态主页。暖白/墨绿编辑式视觉；手机适配、深浅主题、实践筛选、详情展开、任务模板复制。原生 HTML/CSS/JavaScript，无依赖、外部字体、追踪或网络请求。

## 查看

下载 `index.html` 后直接用浏览器打开；或在本目录执行 `python3 -m http.server 8766 --bind 127.0.0.1`，访问 http://127.0.0.1:8766 。不要把这个回环地址当公网地址发给其他人。

## 内容

作品介绍而非实时状态看板。实践文案基于已有论文证据与API预算练习；两幅作品预览为明示的设计示意，不冒充原始数据或截图。没有聊天后端、真实联系表单或虚构客户评价。

## 权限与发布

仓库 `whaleFallWjl/growth-homepage` 必须保持私有。当前未配置外部部署，没有公开网址。源码仓库私有不代表部署站点私有；后续部署必须单独核对站点可见性与用户授权，不为启用Pages而更改仓库公开性。

## 检查

运行 `python3 check.py` 做结构/依赖/JavaScript语法检查。真实浏览器检查记录见 `verification.md`；预览 `desktop.png`、`mobile.png`。

仅主题偏好保存在浏览器localStorage。任务模板复制先尝试Clipboard API，在本地文件环境不可用时尝试浏览器复制回退，均失败则显示提示；没有上传内容。
